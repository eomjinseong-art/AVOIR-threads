# AVOIR(아브아르) Threads 콘텐츠 가이드

@avoireditor 글은 **“따뜻하고 다정한 언니 스타일리스트가 오늘 입을 옷을 골라 주는 이야기”** 로 쓴다.
(2026-10 콘셉트 변경. 이전의 출근복·월요일·쇼핑 습관 독백체 에세이는 쓰지 않는다.)

## 톤
- 다정하고 사랑스럽게, 로맨틱하게. 말을 거는 존댓말("~해 봐요", "~예요", "언니가 골라 줄게요").
- 혼잣말·훈계·자조("~인 것 같다", "~해야 한다") 금지. 독자 편에서 응원한다.
- 작은 이야기 한 장면을 넣는다: 누구와, 어디서, 어떤 마음으로 가는 날인지.

## 한 편의 구성 (200~300자 안팎, 짧은 줄)
1. **장면 한 줄**: "오늘 첫 데이트라고 했죠?", "이번 주말, 엄마랑 카페 가기로 했다면."
2. **이야기 한두 줄**: 그날의 마음·풍경 (설렘, 엄마의 말투, 가을비…).
3. **컬러 팔레트**: 구체적인 색 이름 2~3개 (크림, 버터옐로, 핑크베이지, 오트밀, 카멜, 모카 브라운, 세이지 그린, 라벤더, 버건디, 더스티 핑크…).
4. **소재/질감 한 가지**: 앙고라, 캐시미어, 울, 코듀로이, 새틴, 벨벳, 스웨이드, 트위드, 와플 니트, 플리스… 그리고 그 질감이 주는 느낌.
5. **스타일링 포인트 딱 하나**: 진주 귀걸이 하나, 소매 두 번 접기, 트렌치 끈 뒤로 묶기 등.
6. **가벼운 질문으로 마무리**: "첫 데이트 때 뭐 입었는지 기억나요?" (투표·편 가르기 대신 경험을 묻는 질문)

## 장면·카테고리 (돌아가며)
| 카테고리 | 예시 장면 | 비중 |
|---|---|---|
| 데이트룩 | 20대 첫 데이트·소개팅, 30대 주말·집 데이트, 전시·기차 여행 | 15% |
| 주말나들이 | 단풍·억새·피크닉·캠핑·브런치·시장·송년회 | 15% |
| 모녀코디 | 엄마랑 카페·여행·사진관·백화점, 삼대 가족 모임 | 12% |
| 나를위한옷 | 40~60대 '나를 위한 옷', 지친 주의 위로, 올해의 선물 | 12% |
| 계절 | 일교차, 가을비, 첫 서리, 입동, 패딩·코트 꺼내는 날 | 12% |
| 선물·기념일 | 100일, 생일, 결혼기념일, 빼빼로데이, 크리스마스 | 12% |
| 하객룩 | 가을 야외·겨울·연말 결혼식, 연령별 하객룩 | 8% |
| 질문형 | "딱 한 벌만 산다면 1·2·3", 고민 상담 | 7% |
| 출근룩 | 발표 날, 추운 출근길 등 | **10% 이하** |

- 연령대를 골고루: 20대 첫 데이트 → 30대 주말 → 40·50대 나를 위한 옷 → 모녀 맞춤.
- 같은 카테고리를 3편 연속 쓰지 않는다.
- 시즌을 맞춘다: 10월 중순 단풍·일교차 → 10월 말 할로윈 → 11월 입동·첫눈·빼빼로데이·수능 → 연말·크리스마스.
  큐는 하루 2편씩 나가므로 n번째 글은 대략 시작일 + n/2일에 나간다. 날짜를 못 박는 표현("오늘은 10월 31일")은 피하고 "~이 코앞이에요"처럼 하루 어긋나도 맞는 말로 쓴다.

## 하지 말 것
- 해시태그 0~1개. 링크(`link`)는 10~15편에 1편 정도만 (https://www.avoir24.com).
- 실존 인물·운영자 실명, 가격 단정, 체형 비하("뚱뚱해 보이는"), 나이 비하("이 나이에") 금지.
- 출근·회의·월요일 이야기 반복 금지 (출근룩은 10% 이하).

## 맞춤법 체크 (자주 틀리는 것)
- 카디건(○) 가디건(×), 설렜다(○) 설레였다(×), 손잡다(붙여 씀), 골라 줄게요·입어 봐요(본용언+보조용언은 띄어 씀 원칙)
- 숫자+단위 띄어 쓰기: 두 시간, 1박 2일, 30분, 10년 뒤
- 외래어: 터틀넥, 스웨이드, 메리제인, 루프톱, 코발트블루

## 형식
`content/queue.json` 항목: `{"id": "B071", "category": "데이트룩", "text": "...", "link": "선택"}`
- id는 겹치지 않게 이어서(B071…). 이미 나간 글은 `content/state.json`에 id로 기록된다.
- 큐가 10개 이하로 남으면 이슈 알림이 온다 → 이 가이드로 다음 배치를 쓴다.
- 큐가 비면 구글시트 `출근룩_200_스레드용`(예전 출근룩 콘셉트)의 '미발행' 행이 나간다. 콘셉트가 다르므로 큐가 비기 전에 채우는 것이 원칙.

## 예시
```
오늘 첫 데이트라고 했죠?
언니가 골라 줄게요.

어젯밤 옷 다섯 벌 꺼내 놓고
결국 하나도 못 고른 거, 언니는 다 알아요.

크림 앙고라 니트에
카멜 플리츠 스커트.

앙고라는 가까이 앉았을 때
보송한 결이 먼저 말을 걸어요.

포인트는 하나만.
귀에 작은 진주 하나면 충분해요.

첫 데이트 때 뭐 입었는지 기억나요?
```
